# Holi documentation

This directory explains the current product. It replaces the former Conductor
planning framework with a smaller set of maintained sources of truth.

- `product.md`: products, audiences, and boundaries.
- `architecture.md`: code ownership and deployment architecture.
- `development.md`: lifecycle for product work and releases.
- `privacy.md`: data-flow and disclosure policy.
- `roadmap.md`: current priorities.
- `decisions/`: durable architecture decisions and their consequences.

Normative interfaces and protocols belong in `../spec/`, not here.
