# About Holi Labs

Holi Labs publishes practical tutorials, field notes, experiments, and reviewed
technical papers. It is a seven-locale learning surface, not a backlog or source
of production requirements. Papers are an editorial format inside Labs rather
than a separate Holi product.

## Purpose
- Publish complete English, Spanish, Chinese, Hindi, Arabic, Bengali, and Portuguese guides about local-first web products.
- Organize reading by format, topic, search, and estimated reading time.
- Distinguish tutorials, field notes, experiments, and papers without creating
  separate applications or navigation shells.
- Let readers copy or export material locally in the browser.
- Preserve completed research without forcing experimental architecture into
  the public tools.

## Tech Stack
- Astro
- Tailwind CSS via @holi/configs
- Components via @holi/ui
